# MetaStock Converter

Utility Windows per convertire dati esportati da MultiCharts64 in un formato compatibile con MetaStock.

## Requisiti

- Windows
- .NET Framework 4.0
- Visual Studio o JetBrains Rider

## Utilizzo

1. Avviare l’applicazione.
2. Selezionare un file `.asc` esportato da MultiCharts64.
3. Fare clic su **Analizza**.
4. Controllare i dati visualizzati e procedere con la conversione.

## Avvio da codice

Aprire `MetaStockConverter.sln` con Visual Studio o Rider, quindi compilare ed eseguire il progetto `MetaStockConverter`.

Il progetto utilizza Windows Forms e ha come target `.NET Framework 4.0`.
